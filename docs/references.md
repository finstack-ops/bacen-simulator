# References

Curated source list backing the BACEN/Pix factual claims in this repo's docs (`docs/01-bacen-context.md`, `docs/02-architecture.md`, `ROADMAP.md`, `README.md`, `apps/api/CONTEXT.md`, `apps/spi/CONTEXT.md`). Grouped by topic. **Official** sources (bcb.gov.br, gov.br) are preferred and should be cited first; sources marked **secondary** are private/press sources used where no direct official page was fetched during review — treat their claims as lower-confidence and prefer replacing them with an official source when one is found.

When adding a new factual claim to the docs, add its source here too (see the sourcing policy in `AGENTS.md` and `docs/agents/domain.md`).

## DICT

- **DICT API changelog** — official, current. Backs: DICT API version claims, endpoint/service groups, unilateral fraud markers, MED 2.0 recovery endpoints landing in the API. Version: **2.12.0**, released **2026-06-29**. https://www.bcb.gov.br/content/estabilidadefinanceira/pix/changelog.html
- **DICT API FAQ (v2)** — official. Backs: v2 go-live date (2023-11-05), v1 retirement (2024-02-04), fraud-marker visibility windows (90 days / 12 months / 60 months). https://www.bcb.gov.br/content/estabilidadefinanceira/pix/duvidas_comuns_api_v2.html
- **Manual Operacional do DICT** — official. Backs: DICT entry/claim/key lifecycle description, general DICT operational rules. https://www.bcb.gov.br/content/estabilidadefinanceira/pix/Regulamento_Pix/X_ManualOperacionaldoDICT.pdf
- **`bacen/pix-dict-api` (frozen OpenAPI spec)** — quasi-official (BACEN's own GitHub org, but explicitly frozen/superseded). Backs: DICT vocabulary (Entry, Owner, Account, Key, Reason schema names used in `apps/api/CONTEXT.md`), account-type enum (`CACC`/`TRAN`/`SLRY`/`SVGS`), endpoint tag groups (Directory, Key, Claim, Reconciliation, InfractionReport, Refund, Statistics, Policies). Version: 1.8.0 (historical, references API-DICT-2.0.1 — superseded by 2.12.0 above). https://github.com/bacen/pix-dict-api
- **Rate limiting / "balde de fichas" (BS2 developer docs)** — secondary (bank developer portal, not bcb.gov.br). Backs: token-bucket rate-limit mechanism, per-participant/per-end-user buckets, HTTP 429, participant categories A–F. https://devs.bs2.com/docs/pol%C3%ADticas-de-limita%C3%A7%C3%A3o-de-consulta-%C3%A0-base-dict and https://devs.bs2.com/docs/balde-de-fichas-pix
- **CID / VSync reconciliation (BS2 developer docs)** — secondary. Backs: correction that **CID = "Content Identifier"** (a hash used for sync/reconciliation), not "Cadastro de Identificação de Contas". https://devs.bs2.com/docs/verifica%C3%A7%C3%A3o-de-sincronismo

## SPI / ISO 20022 messages & connectivity

- **Catálogo de Serviços do SFN, Volume VI (Pagamentos Instantâneos)** — official. Backs: `pacs.008`/`pacs.002`/`pacs.004`/`admi.002`/`pibr.001`/`pibr.002` semantics and flow direction, confirmation that `camt.055`/`camt.029` (MED cancellation) and `camt.060`/`camt.053`/`camt.054` (Conta PI query/balance/statement) are part of the Pix message set, and that `pacs.028` is not. Version: **v5.12**. https://www.bcb.gov.br/content/estabilidadefinanceira/cedsfn/Catalogos/Catalogo_de_Servicos_do_SFN_Volume_VI_Versao_512.pdf
- **Catálogo de Serviços do SFN, Volume III** — official. Backs: the generic SFN XML envelope structure (`DOC`/`BCMSG`/`SISMSG`/`USERMSG`) and the `GEN0001` echo-message example. Version: **v5.11**. https://www.bcb.gov.br/content/estabilidadefinanceira/cedsfn/Catalogos/Catalogo_de_Servicos_do_SFN_Volume_III_Versao_511.pdf
- **Guia de Implementação do Canal Secundário de Transmissão de Mensagens** — official. Backs: correction that both SPI primary and secondary channels use ICOM (HTTPS), differentiated by network priority class/port, not IBM MQ vs. HTTPS; concrete secondary-channel hostnames. https://www.bcb.gov.br/content/estabilidadefinanceira/pix/Guia_Implementacao_Canal_Secundario_Transmissao_Mensagens.pdf
- **Manual das Interfaces de Comunicação** — official. Backs: TLS 1.2+ requirement, mandatory mTLS with ICP-Brasil certificates (SPB standard) for RSFN/SPI connections. Version: **v1.12**. https://www.bcb.gov.br/content/estabilidadefinanceira/cedsfn/Manual%20das%20Interfaces%20de%20Comunica%C3%A7%C3%A3o-1.12.pdf
- **Manual de Padrões para Iniciação do Pix** — official. Backs: payment-initiation-adjacent standards referenced from `docs/01-bacen-context.md` section 7. https://www.bcb.gov.br/content/estabilidadefinanceira/pix/Regulamento_Pix/II_ManualdePadroesparaIniciacaodoPix.pdf

## Note on non-official sources

Sources marked secondary above (developer portals of individual banks, law-firm client alerts, Brazilian financial press, and legal-text aggregators like LegisWeb) were used where an official bcb.gov.br page could not be fetched directly during review, or to independently cross-check a fast-moving 2025–2026 regulatory change. They should be treated as lower-confidence than bcb.gov.br/gov.br sources. When updating this file, prefer swapping a secondary source for an equivalent official one if you find it — most normativos (Instruções Normativas, Resoluções) are also mirrored on BCB's own normativo search portal (https://www.bcb.gov.br/estabilidadefinanceira/buscanormas).
